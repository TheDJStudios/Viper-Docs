I'm going to keep this short since we all know math and operators. heres how to do the following with things like variables or comparing:

`*` Multiply by
`+` Add
`-` Subtract
`/` Divide by
`>`Greater than
`<` less than
`=` Equal to

You can also put `-` before a number or variable to make it negative.

```Vp
$ score: int = -10;
```
