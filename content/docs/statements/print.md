Print statements write a value to the screen.

 ## Usage

```Vp
print("Hello");
```

You can print variables, math, function calls, and other expressions.

```Vp
$ count: int = 4;

print(count);
print(count + 1);
```

Make sure to end it with a semicolon `;`.
